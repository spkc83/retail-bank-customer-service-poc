# Retail Bank Servicing Alignment SFT

This card documents the v4 continuation-SFT augmentation generated by
`scripts/retail_bank/prepare_servicing_alignment_data.py`.

The dataset is a local candidate by default. It is not published unless the
preparation script is run with `--push-to-hub`.

## Purpose

The generated dataset keeps the complete released 9,000-record Granite SFT
corpus and adds 427 servicing-alignment records. Keeping the base records in
every split reduces catastrophic-forgetting risk during the next PEFT run.
The augmentation targets POC failure modes that are not well covered by the
released set:

- contextual service-case follow-ups that require `list_service_cases` and
  grounded status, type, subject, and `created_at` wording;
- anaphoric card actions such as replacing or freezing "that one";
- clarification answers after the assistant asks for a public argument;
- user corrections and agent-repair turns;
- banking-to-external topic shifts that should use the stock OOD response;
- external-to-banking topic shifts that should return to tool-backed banking
  service.

## Schema

Every row uses the existing `banking-tool-sft/v1` schema and is validated with
`hello_slm.banking_tool_sft_data.validate_records()`. Tool calls use the public
tool names and public arguments only.

No real customer data is included. User text does not contain private IDs,
account numbers, passwords, PINs, SSNs, phone numbers, or email addresses.

## Splits

The generator writes:

- `train.jsonl`
- `validation.jsonl`
- `test.jsonl`
- `manifest.json`
- `preparation-report.json`

Exact screenshot-derived utterances are reserved for held-out regression rows
in the test split and are not copied into training.

| Split | Released base | Alignment addition | Composite total |
| --- | ---: | ---: | ---: |
| Train | 6,304 | 320 | 6,624 |
| Validation | 1,349 | 80 | 1,429 |
| Test | 1,347 | 27 | 1,374 |

The exact composite split hashes and the base-manifest hash are pinned in
`data/sources/banking-servicing-alignment-v4.lock.json`. Preparation fails if
any of them drift.

## Reproduce

```bash
PYTHONPATH=src python scripts/retail_bank/prepare_servicing_alignment_data.py
```

Publish only after review:

```bash
PYTHONPATH=src python scripts/retail_bank/prepare_servicing_alignment_data.py \
  --push-to-hub \
  --repo-id spkc83/retail-bank-servicing-alignment-sft
```
